# Preview interaction and timeline navigation

The supplied Prime Intellect recording showed live iframes repeatedly disappearing while scrolling down a few captures and back up. The old browser scheduler kept only the nearest two documents and immediately removed the others' `src`. Pointer events were disabled and a full-stage link intercepted clicks, so the embedded scrollbar could not be used.

The new scheduler preloads about two viewport heights in the current scroll direction and half a viewport behind. Selected frames load eagerly rather than relying on a second browser lazy-loading threshold. Only two documents load concurrently. Already loaded documents remain mounted until a bounded cache needs space: eight when the browser reports higher device memory, four for at most 4 GB or Data Saver, six when memory is unavailable. Ordinary short reversals therefore preserve a document's scripts, input state and internal scroll position. A single interacting frame is pinned. Explicit far jumps can preempt unrelated offscreen loading, not visible or interacting documents.

**Interact** enables pointer and keyboard access to the cross-origin archived document. **Done** restores normal outer-page scrolling. The same button works for cached screenshots, but no iframe or archive request is created for those until interaction is explicitly requested. Posters stay visible while their replay loads. A picture of a scrollbar inside a PNG is not interactive. Current/live-site screenshots are not embedded as arbitrary live iframes.

Sandbox tokens remain `allow-scripts allow-same-origin`, with no popup, form, download or top-navigation permission. Autoplay, camera, microphone, geolocation and payment are denied. The replay is never proxied onto the app origin. Loading failures and timeouts remain explicit and retryable; routine successful-load status banners are removed. Cold archive loads and broken archive assets can still delay content, since the parent cannot inspect a cross-origin page's first meaningful paint.

A slow load event is not evidence that the page is blank: real Prime Intellect content painted and scrolled while archive subresources were still pending. A loading deadline must therefore preserve visible or interacting documents rather than tearing down usable content. Offscreen stalled loads can be released to unblock the bounded scheduler.

The minimap follows currently rendered captures, including honest pending and unavailable points. It has stable per-capture anchors, full-date accessible labels, active-position highlighting, and click-to-jump preview priming. The desktop rail sits outside the centered page; below 1180 pixels it becomes a compact fixed picker. Its own overflow scrolls to keep the active dot visible without moving the outer page. It does not change search query history or run new archive searches.

The card UI removes decorative browser chrome, the bottom title row and normal replay-success copy. Compare, interaction and external-open actions sit beside the date. The search input's focus ring follows the rounded outer search box, the label-to-example gap is larger, and routine sampling paragraphs are hidden without leaving a blank gap. Actual errors and live/current provenance remain visible.

`test/preview-scheduler.test.js` uses deliberately delayed and failing replay fixtures to check preloading, budgets, retained state, pressure eviction, one-shot jump priority, interaction, timeout/retry and sandbox isolation across memory profiles. `test/timeline-ui.js` checks real rendered navigation, grouping/stream reconciliation, focus identity, query history, dense short-height rails and mobile layout. These fixtures do not establish Archive fidelity. `tools/check-smooth-previews.js` measures the real Prime Intellect case in a dedicated muted Linux Space; before/after reports and screenshots live in `~/Documents/visual-wayback/scroll-fix/`.

Production verification on November 15, 2026 opened eight real Prime Intellect captures. The old scheduler reassigned the first replay source twice during a short down/up reversal. After the change, traversal through cards 0, 1, 2, 3, 2, 1, 0 kept the first document mounted with one source assignment. In interaction mode, its internal scroll moved from 0 to 708 while the outer page stayed at 702. The document and its internal scroll survived another 22 seconds beyond the initial loading window. This verifies retention and interaction for that replay, not that every capture or archived asset loads successfully. Production search focus, hidden routine copy and the rendered minimap were also checked. The complete 77-test set passed across runs (including the two API tests with an ephemeral server), all seven UI integration scripts passed, and the final slow-load regression passed across all four memory/Data Saver profiles.
