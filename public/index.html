How it works

Sample the archive

We look up captures from the Wayback Machine across your date range. This is a sampled history, not every change.

Group similar text

New searches compare text extracted from archived HTML. Cached examples use rendered text. Different sources are never grouped together.

Compare versions

Browse live replays or cached screenshots, compare text with the previous version, or open a capture in the Wayback Machine.

Know the limits

Archived pages can be incomplete, and HTML can miss JavaScript-only text. Dates show when a page was captured, not when a change first went live.
